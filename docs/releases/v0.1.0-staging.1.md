# v0.1.0-staging.1 release record

Release date: October 6, 2026  
Classification: initial staging candidate  
Repository: independent NextGen Mentorship Platform

## Release boundary

This snapshot freezes the current web mentorship system before application-container packaging and integration with the existing NextGen Portal. It does not modify, deploy, or connect to the live portal.

Included capabilities:

- Optional mentorship entitlement and protected administration.
- Program, cohort, capacity, matching, engagement, and stipend configuration.
- Administrative and public participant applications.
- Application review, approvals, eligibility, and participant records.
- Matching recommendations, administrative decisions, and relationships.
- Goals, sessions, attendance, progress updates, and participant workspace.
- Monitoring dashboards, alerts, completion measurements, and CSV exports.
- Shared Resource Center and participant completion tracking.
- Verified mentor/tutor service hours and explicit stipend decisions.
- Durable notification and email-outbox records for public applications.

## Database

- PostgreSQL schema includes 22 ordered Prisma migrations.

- `prisma migrate deploy` reported no pending migrations.
- Container or staging deployments must run `pnpm db:deploy`; they must not use `prisma migrate dev`.

## Container-stage acceptance gates

Before promoting this snapshot:

1. Build reproducible API and web application images from this tag.
2. Start them with isolated PostgreSQL, Redis, and object-storage services.
3. Run `pnpm db:deploy` as a one-time migration job.
4. Verify health endpoints, login, public application intake, protected mentorship routes, uploads, and email-outbox creation.
5. Test backup and restore using non-production data.
6. Confirm the container receives secrets at runtime and contains no `.env` files.
7. Complete browser-level role and cross-organization access tests.
8. Record image digests and configuration required for rollback.

Only after these gates pass should the NextGen Portal SSO/API integration begin.
